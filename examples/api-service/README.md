# Example: Short Link API

A complete DNA example for a backend API service: a short-link
service. Users register an account, create short links, and the
service redirects visitors and tracks click stats.

This example is intentionally smaller than the SaaS example to
show that the DNA scales to the product — you don't pad a small
API's spec to match a large SaaS's.

- **Vision** in `dna/vision.md`
- **Domains** in `dna/domains/` — 3 (links, redirect, analytics)
- **Features** in `dna/features/<domain>/` — 6 total
- **Flows** in `dna/flows/` — 2
- **Requirements** in `dna/requirements.md`
- **Plan** in `dna/implementation/plan.md`
- **Tasks** in `dna/implementation/tasks.md`
- **Index** in `AGENTS.md`
